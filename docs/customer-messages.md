# 멋테이블 고객 응대 문구 기준
2026년 10월 11일 수정. 고객용 카톡·홈페이지 문구에 적용합니다.

## 답변 원칙
- 고객이 물은 내용부터 답합니다. 가격 질문이면 확인된 가격과 포함 범위를 먼저 알려줍니다.
- 고객의 말을 그대로 되풀이하는 인사, 추상적인 홍보 문장, 긴 등급 설명을 줄입니다.
- 이미 받은 사이즈·수량·수저통 여부는 다시 묻지 않습니다. 견적 확정 전 요약 확인은 필요한 때만 합니다.
- 한 번에 필요한 질문 하나를 묻습니다. 수량과 수저통 유무가 모두 없을 때는 같이 물어도 됩니다.
- 상품은 실제 원목이 아닌 LPM 상판입니다. 무늬 이름과 재질을 구분합니다.
- 납기와 가격은 확인 전 확약하지 않습니다. 통화는 고객이 원할 때 진행하고 카톡에서도 설명합니다.
- 견적 문의 복사문에는 고객의 선택만 넣습니다. 추가 비용 안내는 홈페이지 견적 화면에 표시합니다.
- 기존 챗봇은 비활성 상태를 유지합니다. 이 문서는 고객 응대 기준이며 자동 발송이나 챗봇 재가동 설정이 아닙니다.

## 상황별 예시
첫 문의, 수량과 수저통이 모두 없는 경우:
안녕하세요 사장님. 테이블은 몇 개 필요하세요? 수저통도 같이 필요하실까요?

수량 7개, 수저통 불필요를 이미 답했고 사이즈만 모르는 경우:
생각하신 사이즈가 있을까요?

구성은 모두 받았고 배송 지역이 없는 경우:
수저통 포함해서 견적 보내드릴게요. 배송은 어느 지역으로 해드리면 될까요?

희망 납품일이 10월 20일인 경우, 일정 확인 전:
10월 20일까지 받으실 수 있는지 공장 일정 확인해볼게요.

가격이 확인된 경우:
말씀하신 구성은 총 [확인된 금액]원입니다. [부가세 포함 여부와 배송비 등 별도 비용]입니다.

실제 원목 문의:
저희는 실제 원목이 아닌, 나뭇결 무늬의 LPM 상판으로 제작하고 있어요.

대괄호는 발송 전에 확인한 실제 정보로 바꿉니다. 모르는 가격·일정·성능을 만들어 넣지 않습니다.
