# 멋테이블 공통 저장 연결 준비본

현재 운영의 자동화 기능은 기기 내 저장 모드입니다. 이 폴더는 **아직 배포되지 않은** Google 공통 DB 연결용 코드입니다.

1. `python automation/cloud/build.py`로 현재 콘솔을 묶습니다.
2. 고객 DB 소유자 계정으로 별도의 Apps Script 프로젝트를 만들고 `Code.gs`, 생성된 `App.html`을 넣습니다. 기존 리뷰·접수 스크립트를 덮어쓰지 않습니다.
3. 편집기에서 `setup_`를 실행하고 Google 권한을 승인합니다. 기존 고객DB/문의이력은 읽기만 하며 `_자동화저장` 새 탭에 버전별 원본을 보존합니다.
4. 웹 앱은 **액세스하는 사용자 권한으로 실행 / 접근 권한 나만**으로 배포합니다. 익명 또는 전체 공개 배포 금지. 코드도 설정된 관리자 계정 외 접근을 거부합니다.
5. 개인 창·휴대폰에서 고객 로드, 견적 저장, 입금 기록, 동시 변경 충돌을 확인한 뒤에만 운영 링크를 연결합니다.
6. 기존 콘솔 전체 백업을 내려받은 뒤 새 콘솔에 복원합니다. 공통DB에 기록이 이미 있으면 복원으로 덮어쓰지 말고 개별 병합을 먼저 검토합니다.

신규 홈페이지 문의는 공통 콘솔을 다시 열 때 고객ID 기준으로 추가됩니다. 기존에 불러온 고객의 최신 메모·단계를 무조건 덮어쓰지 않습니다. 자동화 기록은 버전 충돌 시 저장을 중지합니다. Google 저장 오류 상태에서는 백업을 먼저 받습니다.

카카오 발송/은행 조회/정시 알림 연결은 포함하지 않습니다. 외부 고객 메시지는 전송하지 않습니다. 공통 저장 버전은 고객·견적·주문·입금을 공유하며 별도 상담 상세·광고 통계·리뷰 저장소는 기존 방식입니다.
